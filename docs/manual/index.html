    💡 Dica: você não precisa ler tudo de uma vez. Comece pelos primeiros passos, faça o primeiro projeto e depois volte para descobrir blocos novos!

    1. Primeiros passos

    1

    Abra o Beta Blocks

    No computador, abra o Beta Blocks no Google Chrome (ou no Edge). No celular Android, use o Chrome — e dá para instalar como app: menu ☰ → 📲 Instalar app.

    2

    Conecte a placa

    Pelo cabo: ligue a placa no computador com um cabo USB-C e clique em Conectar.
    Sem fio: clique no botão azul de Bluetooth e escolha a placa na lista (o nome começa com Beta-).

    3

    Monte os blocos

    À esquerda ficam as categorias de blocos. Clique numa categoria, arraste um bloco para o meio e encaixe embaixo do ao iniciar. Para apagar um bloco, arraste ele de volta para a lista.

    4

    Envie para a placa

    Clique no ▶ verde. O programa vai para a placa e começa a rodar! Ele fica guardado: quando você ligar a placa de novo, ele roda sozinho. Para parar, use ■ Parar.

    5

    Guarde o seu projeto

    Use ⬇ Baixar para salvar no computador, ou ☁ Salvar para guardar no Google Drive. Para começar do zero, clique em 🗑 Limpar.

    Onde ligar cada coisa na placa

    1, 2, 3Módulos: botões, sensores, potenciômetro, LED, DHT11
    4 e 5Motor M1
    6 e 7Motor M2
    8, 9, 10LED colorido (vermelho, verde e azul)
    11 e 12Visor (a telinha)
    13Buzzer (o som)

    2. Como funciona um programa

    Um programa é uma lista de ordens. A placa faz uma ordem de cada vez, de cima para baixo, como uma receita.

    Este programa faz o LED piscar em vermelho:

    1. ao iniciar: tudo começa aqui, quando a placa liga.
    2. repetir para sempre: faz os blocos de dentro de novo, de novo e de novo...
    3. acende o LED vermelho, espera meio segundo, apaga, espera meio segundo.

    As cores dos blocos

    Cada categoria tem uma cor. Assim fica fácil achar de onde veio cada bloco!

      💡 Blocos soltos não rodam! Um bloco só funciona se estiver encaixado num bloco de evento, como o ao iniciar ou o quando clicar botão.

      4. Projetos para fazer

      🌡️ Termômetro no visor

      Ligue o sensor DHT11 na porta 3. O visor mostra a temperatura a cada 2 segundos.

      Desafio: acenda o LED vermelho quando passar de 30 °C!

      🌀 Ventilador com controle de velocidade

      Ligue o motor no M1 e o potenciômetro na porta 1. Gire o potenciômetro para mudar a velocidade.

      Desafio: troque para ↺ anti-horário e veja o que acontece.

      🎵 Botão musical

      Aperte o botão da porta 1: o LED vira arco-íris e toca uma música!

      Desafio: faça a sua própria música com o bloco ✎ Editar.

      🐱 Controle para o Scratch

      Pareie a placa no Bluetooth do computador (ela aparece como um teclado). No Scratch, use "quando a tecla espaço for pressionada". O botão 1 aperta o espaço e o botão 2 a seta para a direita.

      🦖 Jogo do dinossauro

      Com o visor e dois botões: porta 1 abaixa e porta 2 pula. Também dá para jogar com as setas!

      Desafio: quantos pontos você consegue? Bata o recorde!

      5. Deu problema? Veja aqui

      O botão Conectar ou Bluetooth não funciona

      Use o Google Chrome ou o Edge. No iPhone, o Bluetooth só funciona pelo app Bluefy.

      A placa não aparece na lista do Bluetooth

      Confira se a placa está ligada e perto. A placa conversa com um aparelho por vez: desconecte do outro celular ou computador. No Mac, veja se o Chrome tem permissão de Bluetooth nos Ajustes.

      Enviei o programa e nada acontece

      Veja se os blocos estão encaixados num evento (como o ao iniciar) e se o módulo está na porta certa. Pelo cabo, a aba Console mostra mensagens da placa.

      A placa nunca foi usada (não tem MicroPython)

      No computador, segure o botão BOOT, aperte RESET, solte o BOOT e clique em Gravar MicroPython. Depois aperte RESET e conecte.

      O Bluetooth caiu depois de enviar

      É normal: depois de cada envio a placa reinicia e a ligação cai por 1 ou 2 segundos. O app reconecta sozinho.

      O teclado não digita no Scratch

      Pareie a placa uma vez nos Ajustes de Bluetooth do computador (ela aparece como teclado Beta-…). Depois de cada envio, ela reconecta sozinha.
